# Everyday English V1.0

成人英文學習獨立測試網站。以使用者提供的 Side by Side 第 1、2 冊作課程規劃參考，第一版僅提供第一冊自我介紹主題的原創示範課程，並非兩冊全文。

功能：繁體中文、響應式版面、瀏覽器英文朗讀、可用時的語音辨識、五題測驗及 localStorage 成績保存。

Cloudflare Pages: Connect to Git → 此儲存庫 → Framework preset None → Build command 留空 → Output directory /。請勿覆蓋現有網站。

注意：語音辨識在不同瀏覽器與中國大陸網路環境可能無法使用；學習進度不跨裝置同步。
